# CS2100 Homework 10

> [!CAUTION]
> Make sure the name of this repository / directory has your GitHub username in it. Otherwise, you will not be able to submit any work. You can find the repository with your GitHub username through Pawtograder.


In this homework assignment, you will practice:

- Determining when to use inheritance versus composition
- Designing classes with encapsulation
- Using @classmethod to create an alternative constructor
- Determining when to use a class variable versus an instance variable

You can find the instructions for each question in the corresponding files in the `src` directory. The corresponding tests are in the `tests` directory.

The autograder will also assign points for passing the style and MyPy linters.
